# 1.5.1 archive recovery acceptance

Source: `a17dec5904c2cee909f0a852e509b9aedc189a87`.

The reported archive row could outlive its transcript. Version 1.5.0 returned
`session-not-found` before reconciling the archive registry. Version 1.5.1
acknowledges an already-absent modern JSONL session only after the public storage
API and physical project directories agree. An existing artifact, directory,
symlink, active agent, or unreadable storage prevents this acknowledgement.
Failed archive reconciliation is a failure, not a successful deletion.

## Evidence

- 109 local tests passed, including corrupt/unlisted storage, active ownership,
  absent transcript reconciliation, reconciliation write failure, cancellation,
  path confinement and writer lease behavior.
- [Official DSH CI](https://github.com/WSL043/dsh-chat-manager/actions/runs/35768536758)
  passed on 0.1.7-alpha.1. CodeQL also passed.
- Windows native WebView2: the installed 1.5.1 candidate passed dark and light
  archive/restore, settings-page confirmed deletion, cancelled deletion, stale
  archive deletion, plugin disable/enable and editable composer checks. Image
  annotation and draft preservation also passed. No captured client errors.
- Native fixture is the retained Portable development host (component metadata
  0.7.0-beta.3, actual core 0.1.7-alpha.1), not a fresh 0.7.1 product qualification.
  Installed plugin manifests and host source hashes were checked separately from
  the fixture's immutable bundled-component metadata.
- Final native evidence: local `.artifacts/archive-1.5.1-exact-native.log` and
  the fixture's `acceptance/default-plugin-ui/{dark,light}` screenshots. The
  final installed archive-manager and delete-session source hashes match the
  release candidate. Earlier harness failures and stale-cache results are retained.

Only synthetic sessions in an isolated fixture were destructively tested. No
user conversation was deleted for acceptance. The official inline archive
button and archive menu item are both retained; this release adds neither.
